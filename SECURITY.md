# Security

overfin-web is a client of [Overfin](https://github.com/overfin/server): the
security rules it follows (text from the server is only ever text, which
Svelte escapes, never `{@html}`; everything comes from the site itself;
nothing is sent to a third party) are part of Overfin's, in its
[SECURITY.md](https://github.com/overfin/server/blob/main/SECURITY.md).

## Reporting a vulnerability

Please report it privately, through this repository's **Security** tab
(*Report a vulnerability*), not in a public issue. You'll get an answer, and
credit if you'd like it, once it's fixed.
